# Política de Caché (CACHING.md)

## 💾 Políticas de Caché

- **Archivos Estáticos**: `index.html` servido con encabezados de almacenamiento en caché para assets estáticos.
- **Respuestas LLM**: Al ser consultas dinámicas sobre código, no se almacenan en caché en el servidor para garantizar que las respuestas siempre consideren el contexto actualizado.
