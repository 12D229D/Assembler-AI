# Historial de Cambios (CHANGELOG.md)

Todas las novedades notables de este proyecto serán documentadas en este archivo.

## [1.0.0] - 2026-07-27

### Añadido
- Soporte para Google Gemini SDK (`@google/genai`) con modelo predeterminado `gemini-3.6-flash`.
- Integración multiproveedor para OpenAI (`gpt-4o`), Anthropic (`claude-3-5-sonnet`) y APIs compatibles (Groq/Ollama).
- Panel lateral con navegación por proyectos y chats persistidos en `localStorage`.
- Selector de modelos y configuración de API Keys personales en el frontend.
- Documentación integral `.md` para cobertura completa de ciclo de vida del software.
