# Convenciones de Commits (COMMITS.md)

## 💬 Conventional Commits

Formatos de mensaje de commit aceptados:

- `feat: <descripción>` - Nueva funcionalidad.
- `fix: <descripción>` - Corrección de error.
- `docs: <descripción>` - Cambios en la documentación.
- `refactor: <descripción>` - Reestructuración de código sin cambio de comportamiento.
