# Guardrailes y Restricciones (GUARDRAILS.md)

## 🚧 Salvaguardas del Sistema

1. **Prevención de Explotación Maliciosa Directa**: El modelo está configurado para no generar malware evasivo o exploit payloads destructivos sin contexto ético/educativo.
2. **Límite de Tokens de Entrada y Salida**:
   - Entrada máxima: `8000` caracteres.
   - Salida máxima: `2048` tokens.
