# Convenciones de Nombres (NAMING.md)

## 🏷️ Convenciones de Nombres

- **Variables y Funciones**: `camelCase` (ej. `generateWithGemini`, `activeProjectId`).
- **Interfaces y Tipos**: `PascalCase` (ej. `ChatRequestBody`, `LlmConfig`).
- **Archivos de Configuración**: `kebab-case` o `snake_case` (ej. `metadata.json`, `.env.example`).
