# Guía para Contribuir (CONTRIBUTING.md)

¡Gracias por tu interés en contribuir a **Assembler-AI**! 🚀

## 📋 Proceso de Contribución

1. **Fork y Clonación**: Haz un fork del repositorio y clónalo localmente.
2. **Crear una Rama**: Usa el convenio `feature/nombre-de-funcion` o `fix/descripcion-del-arreglo`.
3. **Desarrollo**:
   - Asegúrate de ejecutar `npm run lint` y verificar que el proyecto compile con `npm run build`.
   - Mantén los estándares de código descritos en `CODE_STYLE.md`.
4. **Pull Request**: Abre un Pull Request detallando los cambios introducidos y la razón de la modificación.
