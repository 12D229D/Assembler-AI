# Proceso de Publicación (RELEASE.md)

## 📦 Flujo de Publicación de Versiones

1. **Verificación de Pruebas**: Ejecutar `npm run build` y comprobación del linter.
2. **Actualizar la Versión**: Incrementar el número de versión en `package.json`.
3. **Registro de Cambios**: Documentar las novedades en `CHANGELOG.md`.
4. **Tag de Git**: Crear una etiqueta `vX.Y.Z` y publicarla en el repositorio.
