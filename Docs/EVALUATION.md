# Evaluación de Resultados (EVALUATION.md)

## 📊 Métricas de Evaluación de Respuestas LLM

- **Precisión Sintáctica**: ¿El código `.asm` generado ensambla sin errores con `nasm -f elf64`?
- **Corrección de Convención de Llamada**: ¿Se respetan los registros asignados según la ABI objetivo?
- **Latencia de Respuesta**: Medición del tiempo transcurrido desde el envío del mensaje hasta el renderizado final.
