# Guía para Revisiones de Código (REVIEW_GUIDELINES.md)

## 🔍 Revisiones de Código

Checklist para revisores de Pull Requests:

1. ¿El cambio compila limpiamente sin advertencias de TypeScript? (`npm run build`).
2. ¿Se mantiene la seguridad de las claves de API?
3. ¿Se actualizó la documentación correspondiente si cambió algún contrato?
