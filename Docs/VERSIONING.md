# Política de Versionado (VERSIONING.md)

## 🔢 Semantic Versioning (SemVer)

**Assembler-AI** utiliza el esquema de versionado semántico `MAJOR.MINOR.PATCH`:

- **MAJOR**: Cambios incompatibles en la API o arquitectura general.
- **MINOR**: Nuevas funcionalidades o proveedores LLM añadidos de forma retrocompatible.
- **PATCH**: Correcciones de errores, mejoras de rendimiento o ajustes de documentación.
