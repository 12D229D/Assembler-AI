# Flujos Funcionales (WORKFLOWS.md)

## 🔄 Flujo de Trabajo del Usuario

1. **Creación de Proyecto**: El usuario hace clic en `+` en la sección de proyectos y asigna un nombre y descripción.
2. **Selección de Proveedor LLM**: En la esquina superior derecha, selecciona el modelo deseado y opcionalmente su API Key.
3. **Interacción y Consulta**: El usuario escribe un problema en la caja de texto. El sistema envía la petición y agrega la respuesta al historial.
