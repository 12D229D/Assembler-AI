# Política de Privacidad (PRIVACY.md)

## 🔒 Privacidad de Datos

- **Sin Rastreo Invasivo**: No vendemos ni comerciamos con los datos del usuario.
- **Almacenamiento Local**: Los mensajes del historial de chat se almacenan exclusivamente en el navegador local (`localStorage`) a menos que el usuario limpie sus datos de navegación.
- **Transmisión Segura**: Las pida de API personalizadas se transmiten mediante peticiones HTTPS directas al proveedor seleccionado.
