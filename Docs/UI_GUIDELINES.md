# Guía Visual de la Interfaz (UI_GUIDELINES.md)

## 🎨 Lineamientos de Interfaz de Usuario

- **Paleta de Colores**:
  - Fondo Principal: `#08111f` (Gris oscuro profundo con tinte azul)
  - Paneles: `#101b2e`
  - Marca / Acento: `#4f8cff` a `#7c3aed` (Degradado púrpura/azul elegante)
  - Texto Principal: `#eef5ff`
- **Tipografía**: Font-family sans-serif moderna (`Inter`, system-ui) combinada con fuente monoespaciada para bloques de código.
