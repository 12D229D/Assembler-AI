# Guía de Actualización (UPGRADE.md)

## ⬆️ Actualizar a la versión 1.0.0

Para actualizar tu versión de **Assembler-AI** a las últimas novedades:

1. Realiza `git pull origin main`.
2. Reinstala dependencias: `npm install`.
3. Revisa la estructura de `.env` respecto a `.env.example`.
4. Borra el almacenamiento en caché del navegador si hay cambios mayores en la UI.
