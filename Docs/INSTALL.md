# Guía de Instalación (INSTALL.md)

## 📦 Requisitos Previos

- Node.js (v18.x o superior)
- npm o bun / yarn

## 🛠️ Pasos de Instalación

1. **Clonar el repositorio**:
   ```bash
   git clone https://github.com/tu-usuario/assembler-ai.git
   cd assembler-ai
   ```

2. **Instalar dependencias**:
   ```bash
   npm install
   ```

3. **Configurar el entorno**:
   ```bash
   cp .env.example .env
   ```

4. **Compilar / Verificar**:
   ```bash
   npm run build
   ```
