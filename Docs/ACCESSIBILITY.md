# Accesibilidad (ACCESSIBILITY.md)

## ♿ Estándares de Accesibilidad (a11y)

1. **Contraste de Color**: Cumplimiento del ratio mínimo WCAG AA (4.5:1) entre el texto y el fondo.
2. **Navegación por Teclado**: Los elementos interactivos como botones y desplegables son enfocables y navegables mediante Tab/Enter.
3. **Etiquetas ARIA**: Atributos `aria-label`, `aria-expanded` y `aria-live="polite"` en el área de conversación.
