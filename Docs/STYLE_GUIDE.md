# Guía de Estilos (STYLE_GUIDE.md)

## 💅 Guía de Estilos de Código

- **CSS / Tailwind / Vanilla**: Uso de variables CSS personalizadas (`:root`) para consistencia en la paleta de colores.
- **HTML**: Atributos `id` únicos en elementos interactivos clave para fácil manipulación DOM y accesibilidad.
- **TypeScript**: Estricto uso de tipos, evitando `any` y formateando con Prettier/ESLint.
