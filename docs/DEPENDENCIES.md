# Dependencias Principales (DEPENDENCIES.md)

## 📦 Lista de Dependencias (`package.json`)

### Dependencias de Producción
- `@google/genai`: SDK oficial para integración con modelos Gemini.
- `express`: Servidor HTTP rápido e imponderable.
- `dotenv`: Carga de variables de entorno desde `.env`.

### Dependencias de Desarrollo
- `typescript`: Lenguaje de programación fuertemente tipado.
- `tsx`: Ejecutor de TypeScript sin paso de compilación previo.
- `@types/express`, `@types/node`: Definicines de tipos para autocompletado e Inferencia.
