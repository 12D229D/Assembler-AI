# Glosario de Términos (GLOSSARY.md)

## 📖 Glosario de Lenguaje Ensamblador

- **NASM**: Netwide Assembler, ensamblador popular para arquitectura x86/x86_64.
- **MASM**: Microsoft Macro Assembler.
- **Registro**: Ubicación de almacenamiento de alta velocidad dentro de la CPU (ej. EAX, RBX, RSP).
- **Opcode**: Código de operación numérico que representa una instrucción ejecutable por el procesador.
- **Stack / Pila**: Estructura LIFO utilizada para almacenar variables locales y direcciones de retorno de funciones.
