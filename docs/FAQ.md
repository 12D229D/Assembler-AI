# Preguntas Frecuentes (FAQ.md)

## ❓ Preguntas Comunes

### 1. ¿Necesito una API Key obligatoriamente para usar la aplicación?
No. Si el servidor tiene configurada una clave global en su archivo `.env`, la aplicación funcionará directamente. Sin embargo, puedes proporcionar tu propia clave desde la interfaz en el selector de proveedores si deseas usar tu cuota personal.

### 2. ¿Qué sintaxis de Ensamblador soporta el asistente?
El asistente reconoce y responde en NASM, MASM, GAS (sintaxis AT&T e Intel) y FASM tanto para x86 (32-bit) como para x86_64 (64-bit).

### 3. ¿Mis chats se guardan en algún servidor?
No. La versión actual guarda tus chats y proyectos localmente en el navegador (`localStorage`).
