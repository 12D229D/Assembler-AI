# Guía de UX (UX_GUIDELINES.md)

## 🎨 Principios de Experiencia de Usuario

1. **Claridad Inmediata**: La aplicación debe abrirse directamente en el entorno de trabajo, sin pantallas de carga innecesarias.
2. **Jerarquía Visual Clara**: Separación distinguible entre el panel lateral de contexto y el área central de chat.
3. **Manejo de Errores Amigable**: Los mensajes de error de la API se muestran dentro del contexto del chat de forma clara e instructiva.
