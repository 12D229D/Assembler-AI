# Modelo del Dominio (DOMAIN_MODEL.md)

## 🧠 Dominio del Sistema

El dominio principal de la aplicación gira en torno a:
1. **Asistencia en Lenguaje Ensamblador**: Dominio conceptual de arquitecturas de CPU (x86, x86_64), registros (`eax`, `ebx`, `rax`, `rsp`), interrupciones y memoria.
2. **Orquestación de Modelos de Lenguaje**: Abstracción de llamadas a LLM para obtener explicaciones técnicas de alto valor.
