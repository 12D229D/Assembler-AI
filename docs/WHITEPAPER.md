# Documento Técnico de Alto Nivel (WHITEPAPER.md)

## 📄 Whitepaper: Assembler-AI

### Resumen Ejecutico
Assembler-AI propone una arquitectura de asistencia mediante inteligencia artificial desacoplada del proveedor de LLM para la enseñanza y optimización de código en Lenguaje Ensamblador x86. Al combinar prompts de sistema estructurados con una interfaz ligera de cliente, reduce la barrera de entrada al desarrollo de bajo nivel.
