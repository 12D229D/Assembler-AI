# Solicitudes de Nuevas Funciones (FEATURE_REQUESTS.md)

## 📬 Formato para Solicitar Funciones

Abre un issue en GitHub con la siguiente plantilla:

- **Título**: `[FEATURE] Breve descripción`
- **Problema que resuelve**: ¿Qué limitación o problema aborda esta función?
- **Solución propuesta**: Describe cómo debería funcionar.
- **Ejemplo de uso**: Proporciona un caso de uso concreto en el contexto de Lenguaje Ensamblador.
