# Tecnologías Utilizadas (TECH_STACK.md)

## 💻 Tech Stack

- **Runtime**: Node.js (TypeScript con `tsx`)
- **Backend Framework**: Express.js
- **Frontend**: HTML5, CSS3 vanilla (Variables CSS y Flexbox/Grid), JavaScript moderno (ES6+)
- **SDKs de Inteligencia Artificial**:
  - `@google/genai` (SDK oficial de Google Gemini)
  - REST Fetch Nativo para OpenAI, Anthropic y Groq
- **Build / Tooling**: TypeScript (`tsc`), `dotenv`
