# Valores del Proyecto (VALUES.md)

## 💎 Valores Fundamentales

1. **Precisión Técnica**: El código de bajo nivel no admite ambigüedades.
2. **Independencia de Proveedor**: Dar libertad al usuario para elegir su modelo de IA preferido.
3. **Privacidad y Respeto**: Trato seguro de las claves API y los datos de los usuarios.
