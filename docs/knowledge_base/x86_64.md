# Manual Técnico: Arquitectura x86-64 / AMD64 (`x86-64`)

**Categoría / Etiqueta**: `x86-64`  
**Descripción Corta**: Arquitectura de 64 bits (también llamada AMD64 o Intel 64), que extiende la arquitectura x86 original para soportar registros y espacios de memoria de 64 bits.  
**Estado**: Estándar de Industria Actual  
**Nivel de Abstracción**: Arquitectura de 64 Bits y Long Mode

---

## 1. Visión General

La arquitectura **x86-64** (creada originalmente por AMD como **AMD64** e adoptada por Intel bajo el nombre **Intel 64** o **EM64T**) es la extensión de 64 bits de la arquitectura IA-32. Rompió la barrera teórica de los 4 GB de RAM, permitiendo direccionar hasta 16 exabytes ($2^{64}$ bytes) de memoria virtual y duplicando la cantidad de registros de propósito general.

---

## 2. Novedades e Innovaciones Arquitectónicas

### 1. Registros Extendidos y Nuevos Registros
- **Registros GPRs de 64 bits**: `RAX`, `RBX`, `RCX`, `RDX`, `RSI`, `RDI`, `RBP`, `RSP`.
- **Nuevos Registros de Propósito General**: `R8`, `R9`, `R10`, `R11`, `R12`, `R13`, `R14`, `R15`.
- Accesibilidad por subpartes: `R8` (64-bit), `R8D` (32-bit), `R8W` (16-bit), `R8B` (8-bit).

### 2. Modo Largo (Long Mode)
- **64-bit Mode**: Modo de ejecución nativo de 64 bits donde los punteros y registros operan a 64 bits.
- **Compatibility Mode**: Permite ejecutar aplicaciones de 16 y 32 bits a velocidad nativa sin emulación en sistemas operativos de 64 bits.

### 3. Direccionamiento Relativo al Registro RIP (RIP-Relative Addressing)
Permite generar **Código Independiente de Posición (PIC - Position Independent Code)** de forma eficiente, haciendo que las referencias a datos sean relativas a la instrucción actual (`[rip + offset]`).

### 4. Paginación de 4 y 5 Niveles (PML4 / PML5)
- **PML4 (48 bits virtuales)**: Soporta hasta 256 TB de memoria virtual y 64 TB de memoria física.
- **PML5 (57 bits virtuales)**: Introducido en procesadores recientes, permite direccionar hasta 128 petabytes de memoria virtual.

## 4. Instrucción Syscall Nativa

x86-64 reemplaza las lentas interrupciones por software (`int 0x80`) por las instrucciones ultrarrápidas `syscall` (Linux) y `sysenter` (Windows).

```nasm
bits 64
section .data
    msg db 'Ejecutando en Modo Largo de 64 bits (x86-64)', 0xA
    len equ $ - msg

section .text
    global _start

_start:
    ; System V AMD64 ABI Syscall (Linux 64-bit)
    mov rax, 1          ; sys_write
    mov rdi, 1          ; stdout
    mov rsi, msg        ; buffer
    mov rdx, len        ; length
    syscall             ; Invocar llamada al sistema de 64 bits

    mov rax, 60         ; sys_exit
    xor rdi, rdi        ; status = 0
    syscall
```
