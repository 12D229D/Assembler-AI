# Guía de Interoperabilidad y Migración: Ecosistema x86/x64 (`x86-x64`)

**Categoría / Etiqueta**: `x86-x64`  
**Descripción Corta**: Término general que agrupa tanto a la arquitectura tradicional de 32 bits (x86) como a su evolución de 64 bits (x64 / x86-64).  
**Estado**: Visión Holística / Arquitectura Mixta  
**Nivel de Abstracción**: Interoperabilidad, Migración y Compatibilidad

---

## 1. Visión General

El término agrupador **x86-x64** (frecuentemente escrito también como `x86/x64` o `x86_64`) engloba la totalidad del ecosistema informático iniciado con procesadores de 32 bits (IA-32) y su extensión dominante de 64 bits (AMD64 / Intel 64). Comprender el continuo `x86-x64` es esencial para garantizar la compatibilidad retroactiva, la portabilidad de código de bajo nivel y la optimización multiplataforma.

---

## 2. Matriz Comparativa: x86 (32-bit) vs x64 (64-bit)

| Parámetro / Característica | x86 (32-bit / IA-32) | x64 (64-bit / AMD64) |
| :--- | :--- | :--- |
| **Tamaño de Punteros / Direcciones** | 32 bits (4 bytes) | 64 bits (8 bytes) |
| **Límite Teórico de Memoria RAM** | 4 GB ($2^{32}$) (64 GB con PAE) | 16 Exabytes ($2^{64}$) |
| **Registros de Propósito General** | 8 (`EAX` ... `EDI`, `ESP`, `EBP`) | 16 (`RAX` ... `R15`) |
| **Registros SIMD/Vectoriales** | 8 (`XMM0` - `XMM7`) | 16 a 32 (`XMM0` - `XMM31`) |
| **Llamada a Syscall por Defecto** | Interrupción `int 0x80` o `sysenter` | Instrucción directa `syscall` |
| **Paso de Parámetros a Funciones** | Principalmente por la pila (cdecl/stdcall) | Por registros (System V / Win64 ABI) |
| **Direccionamiento Relativo** | No nativo (requiere patrones `get_pc`) | Relativo a `RIP` nativo |

---

## 3. Compatibilidad Retroactiva (Compatibility Mode)

Una de las razones clave del éxito comercial de la arquitectura x64 es su capacidad para ejecutar ejecutables de 32 bits sin pérdida de rendimiento mediante el **Modo de Compatibilidad** del procesador:

- En Linux 64 bits, la capa de soporte de 32 bits permite ejecutar binarios ELF32 mediante `multilib` y `ia32-libs`.
- En Windows 64 bits, el subsistema **WOW64 (Windows 32-bit on Windows 64-bit)** redirige transparente llamadas DLL de 32 bits a la capa de ejecución de 64 bits.

---

## 4. Patrones de Código Portable x86/x64

Para escribir código que compile de forma transparente tanto en 32 bits como en 64 bits con NASM, se emplean macros condicionales:

```nasm
%if __BITS__ == 64
    %define PTR_SIZE 8
    %define REG_AX rax
    %define REG_DX rdx
%else
    %define PTR_SIZE 4
    %define REG_AX eax
    %define REG_DX edx
%endif

section .text
global reset_accumulator

reset_accumulator:
    xor REG_AX, REG_AX     ; Se expande a 'xor rax, rax' en 64-bit o 'xor eax, eax' en 32-bit
    ret
```

## 5. Prospectiva y Evolución

En **Assembler-AI**, la etiqueta `x86-x64` actúa como el marco conceptual para:
1. Análisis de migración de aplicaciones legacy a plataformas modernas de 64 bits.
2. Identificación de incompatibilidades de punteros (p. ej., castear punteros de 64 bits a `int` de 32 bits).
3. Estudio de la coexistencia de librerías de 32 bits y 64 bits en entornos de producción y contenedores.
