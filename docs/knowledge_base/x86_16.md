# Manual Técnico: Arquitectura x86 de 16 Bits (`x86-16`)

**Categoría / Etiqueta**: `x86-16`  
**Descripción Corta**: Arquitectura x86 original de 16 bits utilizada en los procesadores Intel 8086 y 80286, con direccionamiento en modo real o protegido primitivo.  
**Estado**: Legado Vivo / Sistemas Embebidos y Bootloaders  
**Nivel de Abstracción**: Modo Real y Modo Protegido Primitivo

---

## 1. Visión General

La arquitectura **x86-16** sienta las bases de la línea de procesadores Intel 8086, 8088, 80186 y 80286. Caracterizada por registros de datos de 16 bits y un esquema de direccionamiento de memoria segmentada, es el punto de partida fundamental para entender el arranque de las computadoras modernas (BIOS/MBR) y los microcontroladores x86.

---

## 2. Direccionamiento en Modo Real (Real Mode)

En Modo Real, el procesador puede direccionar un máximo de **1 MB de memoria física** ($2^{20}$ bytes) utilizando un bus de direcciones de 20 bits.

### Esquema Segmento:Offset
Las direcciones lógicas se representan como `Segmento:Offset`. La dirección física de 20 bits se calcula mediante el desplazamiento del segmento 4 bits a la izquierda (multiplicado por 16):

$$\text{Dirección Física} = (\text{Segmento} \times 16) + \text{Offset} = (\text{Segmento} \ll 4) + \text{Offset}$$

#### Ejemplo:
Si `CS = 0x1000` y `IP = 0x0200`:
$$\text{Dirección Física} = (0x1000 \ll 4) + 0x0200 = 0x10000 + 0x0200 = 0x10200$$

---

## 3. Registros del Procesador de 16 Bits

- **Registros de Datos**: `AX` (`AH`:`AL`), `BX` (`BH`:`BL`), `CX` (`CH`:`CL`), `DX` (`DH`:`DL`).
- **Registros de Índice y Punteros**: `SI` (Source Index), `DI` (Destination Index), `BP` (Base Pointer), `SP` (Stack Pointer), `IP` (Instruction Pointer).
- **Registros de Segmento**: `CS` (Code Segment), `DS` (Data Segment), `SS` (Stack Segment), `ES` (Extra Segment).
- **Registro FLAGS**: Carry (CF), Zero (ZF), Sign (SF), Interrupt Enable (IF), Direction (DF), Overflow (OF).

---

## 4. Modo Protegido Primitivo (Intel 80286)

Introducido en el procesador Intel 80286:
- Amplía el bus de direcciones físicas a 24 bits (16 MB de memoria direccionable).
- Reemplaza el cálculo directo de dirección física por **Selectores de Segmento** que apuntan a Tablas de Descriptores (GDT/LDT).
- Introduce **Anillos de Privilegio** (Ring 0 a Ring 3) para evitar que las aplicaciones modifiquen la memoria del sistema operativo.

---

## 5. Ejemplo Práctico en NASM (Programa MS-DOS / Boot Sector)

### Programa Hola Mundo para MS-DOS (.COM / 16-bit)
```nasm
org 0x100           ; Punto de entrada para ejecutable .COM de MS-DOS
bits 16             ; Generar código de máquina de 16 bits

section .text
start:
    mov ah, 0x09    ; Función DOS para imprimir cadena finalizada en '$'
    mov dx, msg     ; Cargar offset de la cadena
    int 0x21        ; Interrupción de servicio MS-DOS

    mov ax, 0x4C00  ; Terminar programa con código de retorno 0
    int 0x21

section .data
    msg db 'Hola desde x86-16 Real Mode!', 0x0D, 0x0A, '$'
```

## 6. Importancia Actual y Prospectiva

El conocimiento de **x86-16** sigue siendo crucial en:
1. **Desarrollo de Bootloaders**: Los procesadores x86 arrancan obligatoriamente en Modo Real de 16 bits antes de conmutar a 32 o 64 bits.
2. **Sistemas Embebidos y BIOS**: Interacción con rutinas de la BIOS mediante la tabla de vectores de interrupción (`IVT`).
3. **Emulación y Preservación**: Emulación de software retro en emuladores como DOSBox y 8086tiny.
