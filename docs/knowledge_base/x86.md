# Documento Interno: Arquitectura x86 (`x86`)

**Categoría / Etiqueta**: `x86`  
**Descripción Corta**: Arquitectura de microprocesadores de 16 y 32 bits (y su ecosistema general) iniciada por Intel con la familia 8086.  
**Estado**: Activo / Core Reference  
**Nivel de Abstracción**: Arquitectura General

---

## 1. Visión General e Historia

La arquitectura **x86** es una familia de conjuntos de instrucciones (ISA - *Instruction Set Architecture*) basada en el modelo CISC (*Complex Instruction Set Computer*), iniciada comercialmente por Intel en 1978 con el procesador 8086. A lo largo de más de cuatro décadas, x86 se convirtió en el estándar dominante para computadoras personales, servidores y centros de datos.

### Hitos de Evolución
- **8086 / 8088 (1978)**: Introducción del bus de direcciones de 20 bits (1 MB de memoria direccionable) y registros de 16 bits.
- **80286 (1982)**: Introducción del **Modo Protegido**, permitiendo protección de memoria y multitarea básica con hasta 16 MB de memoria física.
- **80386 / IA-32 (1985)**: Transición a 32 bits. Direccionamiento plano (*flat memory model*), registros de 32 bits (EAX, EBX, etc.), unidad de gestión de memoria (MMU) con paginación hardware.
- **80486 y Pentium**: Integración de caché L1/L2 interna, coprocesador matemático (FPU x87 integrado) y ejecución superescalar.

## 2. Modelo de Estado del Procesador (Architecture State)

### Registros Principales de 32 Bits (IA-32)
- **Propósito General**: `EAX` (Acumulador), `EBX` (Base), `ECX` (Contador), `EDX` (Datos), `ESI` (Índice Fuente), `EDI` (Índice Destino), `EBP` (Puntero Base de Marco), `ESP` (Puntero de Pila).
- **Puntero de Instrucción y Banderas**: `EIP` (Instruction Pointer), `EFLAGS` (Carry, Zero, Sign, Interrupt, Overflow, Status flags).
- **Registros de Segmento**: `CS` (Code), `DS` (Data), `SS` (Stack), `ES`, `FS`, `GS` (Extra Segments).

### Diagrama del Modelo de Registros
```

+----------------------------+--------------+---------------+
|                            |      AH      |      AL       | AX (16-bit)
+----------------------------+--------------+---------------+
|                               EAX (32-bit)                |
+-----------------------------------------------------------+
```

## 3. Principios Fundamentales del Ecosistema

1. **Ordenamiento de Bytes (Endianness)**: x86 es estrictamente **Little-Endian**. El byte menos significativo (*LSB*) se almacena en la dirección de memoria más baja.
2. **Modos de Operación**:
   - **Real Mode (Modo Real)**: Modo de compatibilidad 16-bit nativo al encender el CPU.
   - **Protected Mode (Modo Protegido)**: Protección de memoria basada en anillos de privilegio (Ring 0 a Ring 3) e interrupciones protegidas.
   - **Virtual 8086 Mode**: Permite ejecutar aplicaciones de 16 bits dentro de un entorno multitarea de 32 bits.

## 4. Ejemplo de Código Ensamblador Base (IA-32 / NASM)

```nasm
section .data
    msg db "x86 Architecture Overview", 0xA, 0

section .text
    global _start

_start:
    ; Escribir mensaje a stdout usando syscall de Linux (i386)
    mov eax, 4          ; sys_write
    mov ebx, 1          ; fd = stdout
    mov ecx, msg        ; buffer
    mov edx, 26         ; length
    int 0x80            ; Interrupción de llamada al sistema

    ; Salida limpia
    mov eax, 1          ; sys_exit
    xor ebx, ebx        ; exit code = 0
    int 0x80
```

## 5. Prospectiva y Escalabilidad

Aunque x86 surgió en un contexto de 16/32 bits, su diseño flexible permitió la adición de extensiones vectoriales (MMX, SSE, AVX) y la transición sin fisuras a 64 bits (AMD64 / Intel 64). En **Assembler-AI**, las referencias clasificadas bajo la etiqueta `x86` abarcan los fundamentos de codificación de opcodes, modelos de memoria y compatibilidad retroactiva que soportan todas las iteraciones modernas del procesador.
