# Anti-Patrones a Evitar (ANTI_PATTERNS.md)

## 🚫 Anti-Patrones Prohibidos

1. **Hardcoding de API Keys**: Nunca codificar claves privadas directamente en el código fuente.
2. **Fat Controller / Monolito Inmanejable**: Evitar acoplar la lógica de presentación con las llamadas a las APIs de IA.
3. **Uso Excesivo de `any`**: No deshabilitar el sistema de tipos de TypeScript.
