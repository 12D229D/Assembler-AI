# Material de Aprendizaje (LEARNING.md)

## 🎓 Guía de Aprendizaje de Lenguaje Ensamblador

1. **Paso 1**: Entender los registros de propósito general (`EAX`, `EBX`, `ECX`, `EDX`).
2. **Paso 2**: Comprender las operaciones aritméticas y lógicas (`ADD`, `SUB`, `AND`, `XOR`).
3. **Paso 3**: Manejo de flujo con saltos condicionales (`JMP`, `JE`, `JNE`, `JG`, `JL`).
4. **Paso 4**: La Pila (`PUSH`, `POP`, `CALL`, `RET`).
