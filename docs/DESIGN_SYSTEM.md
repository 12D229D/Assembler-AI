# Sistema de Diseño (DESIGN_SYSTEM.md)

## 🧱 Componentes del Sistema de Diseño

- **Botones Primarios**: Fondo en degradado con sombra suave (`box-shadow: 0 4px 14px rgba(79,140,255,0.35)`).
- **Tarjetas y Paneles**: Bordes sutiles semitransparentes (`1px solid rgba(255,255,255,0.12)`) y bordes redondeados de 18px - 24px.
- **Bloques de Código**: Fondo oscuro `#00000073` con padding interno y borde contenedor para destacar las instrucciones ASM.
