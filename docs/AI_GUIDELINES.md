# Buenas Prácticas para IA (AI_GUIDELINES.md)

## 🤖 Guía de Interacción con Inteligencia Artificial

1. **System Prompt Especializado**: Garantizar que el prompt del sistema guíe al LLM a comportarse como un ingeniero experto en ensamblador x86.
2. **Formato de Salida**: Exigir bloques de código delimitados con la sintaxis correspondiente (ej. ````nasm ... ````).
3. **Explicación Pedagógica**: Acompañar el código de ensamblador con un desglose del estado de los registros relevantes.
