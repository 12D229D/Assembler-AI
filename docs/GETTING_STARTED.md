# Primeros Pasos (GETTING_STARTED.md)

Bienvenido a **Assembler-AI**. Sigue estos pasos para comenzar:

1. **Explorar la Interfaz**:
   - **Barra Lateral**: Crea proyectos temáticos (ej. *Bootloaders*, *Simd AVX*) y gestiona tus conversaciones.
   - **Menu Superior ("Multi-LLM")**: Configura tu proveedor preferido (Gemini, OpenAI, Claude o Groq) e ingresa tu API Key si lo deseas.

2. **Formular Preguntas de Alto Impacto**:
   - Incluye el ensamblador/sintaxis objetivo (NASM, MASM, GAS).
   - Adjunta el código `.asm` que deseas analizar o corregir.
