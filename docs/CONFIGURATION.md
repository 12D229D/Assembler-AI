# Configuración del Proyecto (CONFIGURATION.md)

## 🛠️ Variables de Entorno

| Variable | Descripción | Valor por defecto |
| --- | --- | --- |
| `LLM_PROVIDER` | Proveedor por defecto | `gemini` |
| `LLM_SYSTEM_PROMPT` | Prompt del sistema | Expert prompt x86 ASM |
| `LLM_TIMEOUT` | Timeout en segundos | `30` |
| `LLM_MAX_MESSAGE_LENGTH` | Tamaño máximo en caracteres | `8000` |
| `LLM_TEMPERATURE` | Creatividad/Precisión | `0.2` |
| `LLM_MAX_TOKENS` | Tokens de salida | `2048` |
| `GEMINI_API_KEY` | Clave API de Google Gemini | - |
| `OPENAI_API_KEY` | Clave API de OpenAI | - |
| `ANTHROPIC_API_KEY` | Clave API de Anthropic | - |
